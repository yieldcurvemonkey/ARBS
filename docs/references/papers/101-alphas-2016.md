## Abstract

The paper presents explicit formulas for 101 real-life quantitative trading alphas used in production. Key findings:

- **Average holding period**: 0.6-6.4 days (high/mid frequency)
- **Average pairwise correlation**: 15.9% (low correlation, good diversification)
- **Return-volatility relationship**: $R \sim V^{0.76}$ (returns scale with volatility)
- **Turnover independence**: Returns have no significant dependence on turnover
- **Asset class**: Primarily U.S. equities (2,000 most liquid stocks)
- **Data period**: Jan 4, 2010 - Dec 31, 2013 (1,006 observations)

**Key insight**: 80 of these 101 alphas were in production as of December 2015, demonstrating these are not "toy" alphas but real trading strategies.

## Relevance to ARBS (Futures/Swaps)

### Direct Applicability

While these alphas are designed for **equity markets** (using OHLCV data), the fundamental patterns translate to **futures/rates markets**:

1. **Carry signals** - Directly applicable to rates (roll yield, curve slope)
2. **Momentum patterns** - Price trends in futures contracts
3. **Mean-reversion patterns** - Basis convergence, curve reversion
4. **Time-series operators** - Universal across asset classes

### Key Differences: Equities vs Futures

| Aspect | Equities | Futures/Rates |
|--------|----------|---------------|
| **Price data** | OHLC, VWAP | Settlement prices, continuous contract rolls |
| **Volume** | Share volume | Open interest, volume |
| **Carry** | Dividend yield | Roll yield, curve slope, net basis |
| **Cross-section** | Stocks in universe | Contracts across maturities/geographies |
| **Industry neutralization** | GICS sectors | Maturity buckets, currency regions |

### ARBS Translation Strategy

For futures/swaps backtesting, adapt as follows:

1. **`close`** → Settlement price or continuous contract price
2. **`open`** → Previous settlement or intraday open
3. **`volume`** → Contract volume or open interest
4. **`vwap`** → Volume-weighted settlement across day
5. **`rank()`** across instruments → Rank across contracts in universe
6. **`indneutralize()`** → Neutralize by maturity bucket or currency

## Core Concepts

### Mean-Reversion vs Momentum

**Mean-Reversion Alpha** (sign opposite to return):
```python
# Simple equity mean-reversion (Alpha from text, not numbered)
alpha = -ln(today_open / yesterday_close)
```

**Idea**: If stock gaps up at open, expect it to give back gains during the day.

**Futures translation**:
```python
# Futures mean-reversion
alpha = -ln(settlement_t / settlement_t-1)
```

**Momentum Alpha** (sign follows return):
```python
# Simple equity momentum (Alpha from text, not numbered)
alpha = ln(yesterday_close / yesterday_open)
```

**Idea**: If stock ran up yesterday, trend continues today.

**Futures translation**:
```python
# Futures momentum
alpha = ln(settlement_t-1 / settlement_t-2)
```

### Delay Concepts

- **delay-0**: Trade at the time of data used (e.g., at today's close using today's VWAP)
- **delay-1**: Trade next day after data (most common)
- **delay-d**: Trade d days after most recent data

**Note**: Only 4 alphas (42, 48, 53, 54) are delay-0 in this paper.

## Operator Definitions

All operators are **case-insensitive**. Non-integer days `d` converted to `floor(d)`.

### Basic Functions

| Operator | Definition |
|----------|------------|
| `abs(x)` | Absolute value |
| `log(x)` | Natural logarithm |
| `sign(x)` | Sign function: +1, 0, or -1 |
| `x ? y : z` | Ternary conditional |

### Cross-Sectional Operators

**`rank(x)`**: Cross-sectional rank

$$\text{rank}(x_i) = \text{rank of } x_i \text{ among } \{x_1, \ldots, x_N\}$$

Returns values in $[0, N-1]$ or normalized to $[0, 1]$.

**`scale(x, a=1)`**: Rescale x such that $\sum |x_i| = a$

$$\text{scale}(x) = \frac{a \cdot x}{\sum_i |x_i|}$$

Default: $a = 1$ (dollar-neutral portfolio).

**`indneutralize(x, g)`**: Neutralize x against groups g

$$\text{indneutralize}(x, g) = x_i - \text{mean}(x | \text{group}_i)$$

Demeans x within each group (sector, industry, subindustry).

### Time-Series Operators

**`delta(x, d)`**: Difference operator

$$\text{delta}(x, d)_t = x_t - x_{t-d}$$

**`delay(x, d)`**: Lag operator

$$\text{delay}(x, d)_t = x_{t-d}$$

**`ts_min(x, d)`, `ts_max(x, d)`**: Rolling min/max

$$\text{ts\_min}(x, d)_t = \min(x_{t-d+1}, \ldots, x_t)$$

**`ts_argmin(x, d)`, `ts_argmax(x, d)`**: Which day min/max occurred

$$\text{ts\_argmax}(x, d)_t = \arg\max_{i \in [t-d+1, t]} x_i$$

Returns days ago (e.g., 0 = today, 1 = yesterday).

**`ts_rank(x, d)`**: Time-series rank

$$\text{ts\_rank}(x, d)_t = \text{rank of } x_t \text{ in } \{x_{t-d+1}, \ldots, x_t\}$$

**`sum(x, d)`**: Rolling sum

$$\text{sum}(x, d)_t = \sum_{i=0}^{d-1} x_{t-i}$$

**`product(x, d)`**: Rolling product

$$\text{product}(x, d)_t = \prod_{i=0}^{d-1} x_{t-i}$$

**`stddev(x, d)`**: Rolling standard deviation

$$\text{stddev}(x, d)_t = \sqrt{\frac{1}{d} \sum_{i=0}^{d-1} (x_{t-i} - \bar{x})^2}$$

### Statistical Operators

**`correlation(x, y, d)`**: Rolling correlation

$$\text{correlation}(x, y, d)_t = \frac{\text{cov}(x, y, d)_t}{\text{stddev}(x, d)_t \cdot \text{stddev}(y, d)_t}$$

**`covariance(x, y, d)`**: Rolling covariance

$$\text{covariance}(x, y, d)_t = \frac{1}{d} \sum_{i=0}^{d-1} (x_{t-i} - \bar{x})(y_{t-i} - \bar{y})$$

**`decay_linear(x, d)`**: Linearly weighted moving average

$$\text{decay\_linear}(x, d)_t = \frac{\sum_{i=0}^{d-1} (d-i) \cdot x_{t-i}}{\sum_{i=0}^{d-1} (d-i)} = \frac{\sum_{i=0}^{d-1} (d-i) \cdot x_{t-i}}{d(d+1)/2}$$

Weights: $d, d-1, \ldots, 1$ (rescaled to sum to 1).

### Special Functions

**`signedpower(x, a)`**: Signed power

$$\text{signedpower}(x, a) = x^a$$

Preserves sign of x when a is fractional.

## Alpha Formulas by Category

### Category 1: Carry-Like Alphas (Rates-Relevant)

These alphas capture "richness/cheapness" concepts that directly translate to rates markets.

#### Alpha #5: Relative Value vs VWAP
```
(rank((open - (sum(vwap, 10) / 10))) * (-1 * abs(rank((close - vwap)))))
```

**Pattern**: Mean-reversion to 10-day average VWAP, weighted by current deviation.

**Futures translation**:
```python
# Futures: Mean-reversion to average settlement
alpha = rank(settlement - ts_mean(settlement, 10)) * (-abs(rank(settlement - vwap)))
```

**Rates application**: Contract trading rich/cheap relative to moving average basis.

---

#### Alpha #28: Carry + Technical
```
scale(((correlation(adv20, low, 5) + ((high + low) / 2)) - close))
```

**Pattern**: Carry-like signal combining liquidity correlation with intraday range.

**Futures translation**:
```python
# Futures: Correlation of volume with price level + range signal
alpha = scale(correlation(volume_20d, low, 5) + midpoint - close)
```

**Rates application**: Contracts with stable volume and tight ranges (carry candidates).

---

#### Alpha #41: Geometric Mean vs VWAP
```
(((high * low)^0.5) - vwap)
```

**Pattern**: Geometric mean price vs volume-weighted price (richness).

**Futures translation**:
```python
# Futures: Geometric mean of daily range vs settlement
alpha = sqrt(high * low) - settlement
```

**Rates application**: Simple richness indicator for futures contracts.

---

#### Alpha #42: VWAP Ratio (Delay-0)
```
(rank((vwap - close)) / rank((vwap + close)))
```

**Pattern**: Intraday mean-reversion weighted by price level.

**Futures translation**:
```python
# Futures: Intraday settlement vs VWAP
alpha = rank(vwap - settlement) / rank(vwap + settlement)
```

**Rates application**: Intraday trading signal (delay-0, requires intraday data).

### Category 2: Momentum Alphas

#### Alpha #9: Adaptive Momentum/Mean-Reversion
```
((0 < ts_min(delta(close, 1), 5)) ? delta(close, 1) :
 ((ts_max(delta(close, 1), 5) < 0) ? delta(close, 1) :
  (-1 * delta(close, 1))))
```

**Pattern**: Momentum if trending (all positive or all negative last 5 days), else mean-reversion.

**Futures translation**: Direct application to settlement returns.

**Rates application**: Trend-following when rates clearly trending, fade otherwise.

---

#### Alpha #12: Volume-Price Divergence
```
(sign(delta(volume, 1)) * (-1 * delta(close, 1)))
```

**Pattern**: Contrarian to price moves with volume spikes.

**Futures translation**:
```python
# Futures: Fade price moves on volume spikes
alpha = sign(delta(volume, 1)) * (-delta(settlement, 1))
```

**Rates application**: Mean-reversion signal when volume surges.

---

#### Alpha #43: Momentum + Volume Confirmation
```
(ts_rank((volume / adv20), 20) * ts_rank((-1 * delta(close, 7)), 8))
```

**Pattern**: Momentum (negative delta) confirmed by elevated volume.

**Futures translation**: Direct application with contract volume.

**Rates application**: Short-term momentum trades with volume confirmation.

### Category 3: Mean-Reversion Alphas

#### Alpha #1: Volatility-Adjusted Reversion
```
(rank(Ts_ArgMax(SignedPower(((returns < 0) ? stddev(returns, 20) : close), 2.), 5)) - 0.5)
```

**Pattern**: Time since peak (volatility if negative return, else close).

**Futures translation**:
```python
# Futures: Time since volatility peak or price peak
alpha = rank(ts_argmax(
    signedpower(stddev(returns, 20) if returns < 0 else settlement, 2), 5
)) - 0.5
```

**Rates application**: Mean-reversion timing based on volatility regime.

---

#### Alpha #53: Intraday Range Mean-Reversion (Delay-0)
```
(-1 * delta((((close - low) - (high - close)) / (close - low)), 9))
```

**Pattern**: Change in intraday position within range.

**Futures translation**:
```python
# Futures: Position within daily range
alpha = -delta(((settlement - low) - (high - settlement)) / (settlement - low), 9)
```

**Rates application**: Intraday mean-reversion (requires high/low data).

---

#### Alpha #54: Asymmetric Range Ratio (Delay-0)
```
((-1 * ((low - close) * (open^5))) / ((low - high) * (close^5)))
```

**Pattern**: Complex non-linear mean-reversion signal.

**Futures translation**: Direct application (caution: high power terms).

**Rates application**: Advanced mean-reversion for high-frequency strategies.

### Category 4: Cross-Sectional Alphas

#### Alpha #3: Open-Volume Correlation
```
(-1 * correlation(rank(open), rank(volume), 10))
```

**Pattern**: Fade instruments where price and volume are correlated.

**Futures translation**:
```python
# Futures: Fade contracts with price-volume correlation

```

**Rates application**: Contrarian signal for contracts with unusual volume patterns.

#### Alpha #13: Close-Volume Covariance Rank
```
(-1 * rank(covariance(rank(close), rank(volume), 5)))
```

**Pattern**: Short high covariance (momentum/liquidity seeking).

**Futures translation**: Direct application.

**Rates application**: Fade contracts where price moves with volume.

#### Alpha #55: Range Breakout + Volume
```
(-1 * correlation(rank(((close - ts_min(low, 12)) / (ts_max(high, 12) - ts_min(low, 12)))),
                  rank(volume), 6))
```

**Pattern**: Fade breakouts confirmed by volume.

**Futures translation**: Direct application.

**Rates application**: Mean-reversion after range breakouts.

### Category 5: Multi-Factor Combinations

#### Alpha #101: Simple Intraday Momentum
```
((close - open) / ((high - low) + .001))
```

**Pattern**: Intraday momentum normalized by range.

**Futures translation**:
```python
# Futures: Settlement move normalized by range
alpha = (settlement - open) / (high - low + 0.001)
```

**Rates application**: Simple intraday signal (delay-1).

#### Alpha #36: Complex Multi-Factor
```
(((((2.21 * rank(correlation((close - open), delay(volume, 1), 15))) +
    (0.7 * rank((open - close)))) +
    (0.73 * rank(Ts_Rank(delay((-1 * returns), 6), 5)))) +
   rank(abs(correlation(vwap, adv20, 6)))) +
  (0.6 * rank((((sum(close, 200) / 200) - open) * (close - open)))))
```

**Pattern**: Weighted combination of multiple signals (momentum, mean-reversion, volume).

**Futures translation**: Adapt each component separately.

**Rates application**: Multi-factor model combining trend, reversion, and volume.

```python
"""Time-series and cross-sectional operators from Kakushadze (2015)."""

import numpy as np
import pandas as pd
from scipy import stats

def rank(x: pd.Series) -> pd.Series:
    """Cross-sectional rank (0 to N-1)."""
    return x.rank(method='average', pct=False) - 1

def scale(x: pd.Series, a: float = 1.0) -> pd.Series:
    """Scale such that sum(abs(x)) = a."""
    return a * x / x.abs().sum()

def ts_rank(x: pd.Series, d: int) -> pd.Series:
    """Time-series rank over past d days."""
    return x.rolling(d).apply(lambda s: stats.rankdata(s)[-1], raw=True)

def ts_delta(x: pd.Series, d: int) -> pd.Series:
    """Delta: x[t] - x[t-d]."""
    return x.diff(d)

def ts_correlation(x: pd.Series, y: pd.Series, d: int) -> pd.Series:
    """Rolling correlation."""
    return x.rolling(d).corr(y)

def ts_covariance(x: pd.Series, y: pd.Series, d: int) -> pd.Series:
    """Rolling covariance."""
    return x.rolling(d).cov(y)

def decay_linear(x: pd.Series, d: int) -> pd.Series:
    """Linearly decaying weighted moving average."""
    weights = np.arange(1, d + 1)
    return x.rolling(d).apply(lambda s: np.dot(s, weights) / weights.sum(), raw=True)
```

```python
class RatesCarryAlpha5(FormulaicAlpha):
    """Alpha #5 adapted for rates: mean-reversion to average."""

    def calculate_signal(self, returns: pd.DataFrame,
                        settlements: pd.DataFrame,
                        **kwargs) -> pd.DataFrame:
        # rank((settlement - mean(settlement, 10)) * (-abs(rank(settlement - vwap))))
        mean_settlement = settlements.rolling(10).mean()
        deviation = settlements - mean_settlement

        # Cross-sectional ranks
        rank_dev = deviation.rank(axis=1, pct=True)
        rank_current = (settlements - settlements.mean(axis=1, keepdims=True)).rank(axis=1)

        signal = rank_dev * (-rank_current.abs())
        return self._apply_scaling(signal)
```

## Key Empirical Results

### Return-Volatility Relationship

$$R \sim V^{0.76}$$

**Implication for ARBS**: Scale alpha signals by volatility forecasts (already implemented in `AlphaGenerator`).

**Formula**:
$$\alpha_i = IC \times \sigma_i \times z_i$$

Where:
- $IC$ = information coefficient
- $\sigma_i$ = volatility forecast
- $z_i$ = z-score of raw signal

This matches Kakushadze's empirical finding that returns scale with volatility to the 0.76 power.

### Turnover Independence

**Finding**: Returns have **no significant dependence on turnover**.

**Implication**: High turnover alphas are not inherently less profitable (but costs matter).

**ARBS impact**: Don't penalize high-frequency signals purely on turnover; focus on net-of-cost performance.

### Low Correlation

**Average pairwise correlation**: 15.9%

**Implication**: Combining multiple alphas provides strong diversification.

**ARBS strategy**: Implement multiple formulaic alphas and combine via `SignalCombiner`:

## Limitations and Considerations

### 1. Equity vs Futures Data Differences

**Problem**: OHLCV data less granular for futures (settlement-based).

**Solution**:
- Use settlement prices as "close"
- Open interest as volume proxy
- Forward curves for "cross-section"

### 2. Continuous Contract Adjustments

**Problem**: Futures require roll adjustments.

**Solution**:
- Use returns (already roll-adjusted)
- Avoid level-based signals (e.g., `close^5`)
- Apply signals to continuous contracts

### 3. Universe Size

**Problem**: Rates universe smaller than 2,000 stocks.

**Solution**:
- Cross-sectional ranks across contracts (e.g., 20-30 futures)
- Industry neutralization → maturity bucket neutralization
- Lower expected correlation (fewer instruments)

### 4. Transaction Costs

**Problem**: Formulaic alphas can have high turnover.

**Solution**:
- Implement quadratic costs in optimizer (see `quadratic-costs-2020.md`)
- Use holding period analysis (1/T) to filter high-turnover alphas
- Cost-aware alpha scaling

### ARBS Implementation

```python
# /home/user/ARBS/arbs/signals/formulaic/alpha_012.py

"""
ABOUTME: Alpha #12 from Kakushadze (2015) - Volume-Price Divergence
ABOUTME: Contrarian signal: fade price moves accompanied by volume spikes
"""

import pandas as pd
from arbs.signals.base_signal import BaseSignal

class Alpha12(BaseSignal):
    """
    Volume-Price Divergence Signal.

    Pattern: Contrarian to price moves with volume spikes.
    - If volume increases and price rises → short (expect reversion)
    - If volume increases and price falls → long (expect reversion)

    Original: sign(delta(volume, 1)) * (-1 * delta(close, 1))

    Futures adaptation:
    - close → settlement price
    - volume → contract volume or open interest
    """

    def __init__(self, lookback: int = 1, **kwargs):
        super().__init__(**kwargs)
        self.lookback = lookback

    def calculate_signal(
        self,
        returns: pd.DataFrame,
        volume: pd.DataFrame,
        prices: pd.DataFrame = None,
        **kwargs
    ) -> pd.DataFrame:
        """
        Calculate volume-price divergence signal.

        Parameters
        ----------
        returns : pd.DataFrame
            Settlement-to-settlement returns (already computed)
        volume : pd.DataFrame
            Contract volume time series
        prices : pd.DataFrame, optional
            Settlement prices (can reconstruct from returns if needed)

        Returns
        -------
        pd.DataFrame
            Signal matrix (instruments × time)
        """
        # Volume change direction
        volume_delta_sign = volume.diff(self.lookback).apply(lambda x: x.map(self._sign))

        # Price change (use returns directly)
        price_delta = returns  # Returns already represent delta(close, 1)

        # Contrarian signal: fade price moves with volume
        raw_signal = volume_delta_sign * (-price_delta)

        # Cross-sectional normalization (dollar-neutral)
        signal = self._normalize_cross_sectional(raw_signal)

        return signal

    @staticmethod
    def _sign(x: float) -> int:
        """Sign function: +1, 0, or -1."""
        if x > 0:
            return 1
        elif x < 0:
            return -1
        else:
            return 0

    def _normalize_cross_sectional(self, signal: pd.DataFrame) -> pd.DataFrame:
        """Normalize to dollar-neutral (sum of absolute values = 1)."""
        return signal.div(signal.abs().sum(axis=1), axis=0).fillna(0)


# Unit test
def test_alpha12_volume_spike_fade():
    """Test Alpha #12 fades price moves with volume spikes."""
    import numpy as np

    # Mock data: 5 instruments, 10 days
    dates = pd.date_range('2024-01-01', periods=10)
    instruments = [f'FUT{i}' for i in range(5)]

    # Instrument 0: Price up, volume up → expect negative signal
    returns = pd.DataFrame(0.0, index=dates, columns=instruments)
    returns.loc[dates[5], 'FUT0'] = 0.01  # Price spike

    volume = pd.DataFrame(1000, index=dates, columns=instruments)
    volume.loc[dates[5], 'FUT0'] = 2000  # Volume spike

    alpha = Alpha12()
    signal = alpha.calculate_signal(returns=returns, volume=volume)

    # Signal should be negative (fade the price spike)
    assert signal.loc[dates[5], 'FUT0'] < 0
    print("✓ Alpha #12 test passed")

if __name__ == '__main__':
    test_alpha12_volume_spike_fade()
```

```python
    alpha_generator=alpha_gen,
    covariance_model=cov_model,
    optimizer=optimizer
)

results = backtest.run(
    returns=futures_returns,
    volume=futures_volume,
    start_date='2020-01-01',
    end_date='2023-12-31'
)

print(f"Sharpe Ratio: {results.sharpe_ratio:.2f}")
print(f"Annual Return: {results.annual_return:.2%}")
print(f"Turnover: {results.turnover:.2%}")
```
