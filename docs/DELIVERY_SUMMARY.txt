================================================================================
KEY ARCHITECTURAL INSIGHTS DOCUMENTED
================================================================================

1. Product Agnosticism via Adapter Pattern
   - Backtester doesn't know about specific products
   - Each product self-registers with ProductAdapter
   - New products extend without modifying core engine

2. Structure/Value Decoupling
   - Clear separation: what to build vs. how to value
   - Enables flexible composition and metric selection
   - Supports both outright positions and spreads

3. Backend Flexibility
   - Generic interfaces allow QuantLib ↔ RatesLib swaps
   - Definitions maps centralize backend-specific config
   - Zero impact on query layer

4. Risk-Weighted Multi-Leg Structures
   - Linear algebra solver for notional distribution
   - Intuitive spread/fly construction
   - Maintains risk weight invariants

5. Type Safety Through Frozen Dataclasses
   - Immutability by design
   - Clear data contracts
   - Prevents accidental mutations

6. Extensibility
   - Well-defined patterns for new products
   - ~1000 LOC per product following patterns
   - Clear checklist for implementation
